# Kido animated stickers

פרויקט מקור לסטיקרים מונפשים של קידו, לשימוש בעיקר ב־WhatsApp.

## מצב העבודה

182 סטיקרים בקטלוג: בנים, בנות, בנים עם כיפה ומוצרים בעברית ובאנגלית.
היצירה מתקדמת בחבילות. מצב כל סטיקר נשמר ב־`catalog.json`.
תיקיית `assets/source/curated` שומרת גם את הבחירות הסופיות הקודמות.
אין לראות תמונת מקור או סטיקר במצב `pending` כאנימציה מוכנה.

[מצב התקדמות וחבילות להורדה](docs/progress.md) · [גלריה מקומית](preview.html)

## מבנה

- `assets/source/` — איורי מקור וגרסאות קודמות, נשמרו להמשך עריכה.
- `assets/reference/` — לוגו, תמונות מוצרים והשוואות סגנון.
- `animations/` — פריימים ופרומפטים של אנימציות שהופקו.
- `dist/` — תוצרי WebP מונפשים שעברו בדיקה.
- `catalog.json` — מזהים קבועים, כיתובים, מקורות ומצב הפקה.
- `scripts/` — כלים למיפוי ולייצוא.
- `scripts/legacy/` — מחוללי התמונות המקוריים; הם משתמשים ב־API חיצוני ועלולים לחייב כסף. אין להריץ אותם במסגרת העבודה הנוכחית.
- `docs/legacy/` — הפרומפטים והתיעוד המקוריים.
- `work/` — חומרי עבודה זמניים שאינם עולים ל־Git.

## יצירה ועריכה

נעזרים ב־hatch-pet לשמירה על זהות הדמות, יצירת רצף תנוחות נפרד לכל סיטואציה ובקרת פריימים. יעד הפרויקט הוא סטיקרים ל־WhatsApp; אלה אינם חבילות חיות Codex בפורמט v2.

מייצרים תנוחות באמצעות כלי imagegen המובנה בלבד, במסגרת המנוי הקיים. אין אישור להוצאות נוספות או ל־API בתשלום. עוצרים אם מופיעה מגבלת שימוש.

כל אנימציה חייבת לכלול תנועה מתאימה לסיטואציה, ולא רק הזזה או סיבוב של תמונת המקור. שומרים את המקורות והפריימים כדי לאפשר שינוי בעתיד.

## ייצוא מקומי

```sh
pip install -r requirements.txt
python scripts/export_animation.py animations/boy-kippah-01/frames dist/boy-kippah-01/01.webp
python scripts/export_animation.py --validate dist/boy-kippah-01/01.webp
```

להפקה חוזרת מרצועת תנוחות קיימת, שמרו אותה ב־`animations/<id>/source-strip.png`, הריצו `python scripts/assemble_sticker.py <id>` ובדקו את `contact-sheet.jpg`. לאחר תיעוד QA, הריצו `python scripts/accept_qa.py`. אריזת חבילה מלאה: `python scripts/package_pack.py --collection boy-kippah --pack 1`. עדכון הגלריה: `python scripts/build_gallery.py`.

הקלט לייצוא הוא תיקייה עם פריימים שקופים בגודל 512×512 ושמות עוקבים.

לפי [מפרט WhatsApp](https://github.com/WhatsApp/stickers/blob/main/Android/README.md), סטיקר מונפש הוא WebP בגודל 512×512, עד 500KB, משך עד 10 שניות ולפחות 8 מילישניות לפריים. חבילה מכילה 3–30 סטיקרים מונפשים, ואינה מערבבת סטטיים ומונפשים. ייבוא לטלפון דורש אפליקציה שתומכת בחבילות סטיקרים מונפשים; קובץ WebP בפני עצמו אינו מתקין חבילה אוטומטית.

## ניקוי ואבטחת מקורות

הוסרו שני עותקי תמונה זהים ברמת הבתים ומטמון Python. כל תמונה ייחודית נשמרה. הדוח נמצא ב־`docs/cleanup-report.json`.
מפתחות API שהיו מוטמעים בסקריפטים הוסרו לפני יצירת היסטוריית Git. סקריפטים ישנים מקבלים מפתח ממשתנה סביבה בלבד. אין לשמור מפתחות במאגר.
